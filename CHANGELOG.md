- Initial release.
- Playable JezzBall game in an Explorer side-bar webview.
- `JezzBall: Play` command and `Ctrl/Cmd + Alt + J` keybinding.
- Windows 95-styled UI with pause and mute.
- Auto-fit to panel width.
